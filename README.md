# 📦 سیستم مدیریت انبار — کارخانه قند صنوبر

سیستم سبک و آفلاین مدیریت انبار برای ثبت **ورود و خروج کالا** با امکان همگام‌سازی خودکار روی **GitHub**.

---

## ✨ امکانات

- 📥📤 **ثبت ورود و خروج کالا** با فرم ساده و سریع
- ⚖️ **محاسبه خودکار وزن (kg)** بر اساس ضریب تبدیل هر واحد
- 📅 **تقویم شمسی** داخلی + انتخابگر ساعت
- 🔍 **جستجوی هوشمند چندکلمه‌ای** (مثلاً: `کارتن ۳`، `شکر احمدی`)
- 📊 **خلاصه ورود و خروج** طبق فیلتر فعال
- 🖨️ **گزارش‌های چاپی A5** (رسید تک + گزارش گروهی + خلاصه)
- 📄 **خروجی CSV** از رکوردها
- ☁️ **همگام‌سازی با GitHub** (دریافت/ذخیره + تشخیص تداخل)
- 💾 **پیش‌نویس خودکار فرم** — اگر مرورگر بسته شد، اطلاعات فرم حفظ می‌شود
- 🌙 **حالت شب** و تم تمیز و مدرن
- 📱 **ریسپانسیو** — روی موبایل، تبلت و دسکتاپ

---

## 🚀 راه‌اندازی

### ۱. باز کردن برنامه

فایل `index.html` رو با مرورگر (Chrome / Firefox / Edge) باز کن. تمام!

### ۲. تنظیم اتصال GitHub

روی آیکن **☰** (گوشه بالا-راست) بزن و اطلاعات زیر رو وارد کن:

| فیلد | مقدار |
|------|-------|
| GitHub Username | نام کاربری گیت‌هاب |
| Repository Name | اسم مخزن (مثلاً `WH`) |
| Personal Access Token | توکن با دسترسی `Contents: Read and write` |

سپس **💾 ذخیره و تست اتصال** رو بزن.

### ۳. شروع به کار

- دکمه **ورود کالا** یا **خروج کالا** رو بزن
- فرم رو پر کن و **ثبت** بزن
- در پایان روز **⬆️ ذخیره** رو بزن تا اطلاعات روی GitHub بره

---

## 🔑 ساخت Personal Access Token

1. برو به [github.com/settings/tokens](https://github.com/settings/tokens)
2. **Generate new token** → **Fine-grained token**
3. توی بخش **Repository access** فقط مخزن `WH` رو انتخاب کن
4. توی **Permissions** → **Contents** → **Read and write**
5. توکن رو کپی کن و توی برنامه وارد کن

> ⚠️ **مهم:** توکن رو جایی عمومی قرار نده. توی خود برنامه (توی حافظه مرورگر) ذخیره می‌شه و به GitHub نمی‌ره.

## 🔍 نمونه‌های جستجو

| عبارت | نتیجه |
|-------|-------|
| `کارتن` | همه رکوردهای کارتنی |
| `کارتن ۳` | کارتن‌هایی با تعداد ۳ |
| `کیسه ۵۰` | کیسه‌های ۵۰ تایی |
| `شکر` | همه رکوردهای شکر |
| `احمدی ۱۰۰` | رکوردهای راننده احمدی با تعداد ۱۰۰ |
| `kg` | همه رکوردهای وزنی |

> 💡 **ترتیب کلمات مهم نیست** — `کارتن ۳` و `۳ کارتن` یکسانن.

## 💾 پشتیبان‌گیری

از منوی **☰** دو راه برای بکاپ داری:

1. **⬇️ دانلود پشتیبان JSON** — یک فایل روی کامپیوتر ذخیره می‌شه
2. **☁️ همگام‌سازی GitHub** — خودکار روی مخزن ذخیره می‌شه

> 🔔 توصیه: هر چند وقت یکبار بکاپ JSON بگیر تا خیالت راحت باشه.

## ⚙️ نکات فنی

- **بدون نصب و بدون سرور** — فقط یک فایل HTML
- **همه داده‌ها در مرورگر ذخیره می‌شن** (localStorage) و با دکمه ذخیره به GitHub می‌رن
- **بدون کتابخانه خارجی** — تمام کد بومی JavaScript
- **تقویم شمسی** به‌صورت داخلی پیاده‌سازی شده
- **کد قابل چاپ در A5** — مناسب پرینترهای اداری

---

## 🆘 رفع مشکلات رایج

**🔴 خطای ۴۰۳ هنگام ذخیره**
> توکن دسترسی نوشتن نداره. توکن جدید با `Contents: Read and write` بساز.

**🔴 اطلاعات ثبت می‌شن ولی روی GitHub نمی‌رن**
> باید بعد از ثبت، دکمه **⬆️ ذخیره** رو بزنی.

**🔴 برنامه در مرورگر باز نمی‌شه**
> مطمئن شو فایل با پسوند `.html` ذخیره شده و با مرورگر (نه ویرایشگر متن) بازش می‌کنی.

**🔴 فایل `data.json` روی GitHub پیدا نمی‌شه**
> بار اول که دکمه **⬆️ ذخیره** رو بزنی، خودکار ساخته می‌شه.
