## 🚀 شروع سریع

### مرحله ۱ — دریافت فایل
فایل `index.html` را در یک پوشه ذخیره کنید.

### مرحله ۲ — باز کردن
با دابل‌کلیک روی فایل، آن را در مرورگر باز کنید.
(توصیه می‌شود از **Chrome** یا **Edge** استفاده کنید.)

### مرحله ۳ — تنظیم GitHub (اختیاری ولی توصیه‌شده)
از منوی ☰ بالای صفحه، بخش **«☁️ اتصال GitHub»** را باز کنید و اطلاعات را وارد کنید.
بدون این تنظیمات، برنامه آفلاین کار می‌کند ولی بین چند کاربر همگام نمی‌شود.

## ☁️ تنظیمات GitHub

### مرحله ۱ — ساخت Repository

1. وارد [github.com](https://github.com) شوید
2. روی **New repository** کلیک کنید
3. نام: `Warehouse` (یا هر نام دلخواه)
4. **Private** یا Public — فرقی ندارد
5. ✅ گزینه **Add a README file** را تیک بزنید
6. **Create repository**

### مرحله ۲ — ساخت Personal Access Token

1. بروید به **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens**
2. روی **Generate new token** کلیک کنید
3. تنظیمات:
   - **Name:** `Warehouse Token`
   - **Expiration:** هر چقدر می‌خواهید (مثلاً 1 year)
   - **Repository access:** فقط همون مخزن `Warehouse` رو انتخاب کنید
   - **Permissions** → **Repository permissions** → **Contents: Read and write** ✅
4. **Generate token** را بزنید
5. توکن (که با `github_pat_...` شروع می‌شه) رو **کپی** کنید

> ⚠️ این توکن فقط **یک بار** نمایش داده میشه — حتماً ذخیره کنید

### مرحله ۳ — وارد کردن در برنامه

از منوی ☰ → **☁️ اتصال GitHub**:

| فیلد | مقدار |
|---|---|
| GitHub Username | نام کاربری گیت‌هاب شما |
| Repository Name | `Warehouse` |
| Personal Access Token | توکن کپی‌شده |

سپس **💾 ذخیره و تست اتصال** را بزنید.

### مرحله ۴ — استفاده

- **⬇️ دریافت:** اطلاعات از GitHub به مرورگر می‌آید
- **⬆️ ذخیره:** اطلاعات مرورگر به GitHub فرستاده می‌شود

> 💡 نوار بالای صفحه وضعیت اتصال رو نشان می‌دهد:
> - 🟢 همه چیز ذخیره شده
> - 🟠 تغییرات ذخیره‌نشده
> - 🔒 توکن فقط خواندنی
> - ❌ خطا در اتصال

## 🔐 پسورد بخش پشتیبان

بخش **«📁 پشتیبان فایلی»** در تنظیمات، با پسورد محافظت می‌شود.

### پسورد پیش‌فرض

```
#Aa09151217270
```

### نحوه کار

1. روی هدر **«📁 پشتیبان فایلی»** کلیک کنید
2. مودال پسورد باز می‌شود
3. پسورد را وارد کنید
4. **۳ بار** اشتباه = دسترسی رد می‌شود
5. پس از ورود موفق:
   - آیکن 🔓 نمایش داده می‌شود
   - دکمه **🔒 قفل کردن** در هدر ظاهر می‌شود
6. با **بستن تب** یا **دکمه 🔒**، بخش مجدداً قفل می‌شود

### چرا این پسورد؟

- این پسورد جلوی **کاربر عادی انبار** را می‌گیرد
- برنامه پسورد را به‌صورت **Base64** ذخیره می‌کند (نه متن ساده)
- کاربر فنی با DevTools می‌تواند دور بزند — این یک لایه **UX** است نه امنیت واقعی

## 📦 مدیریت کالا و واحد

### افزودن کالا

از منوی ☰ → **📦 کالاها و زیرمجموعه‌ها** → **➕ افزودن کالای جدید**

فرم شامل:
1. **نام کالا** (مثلاً: شکر)
2. **واحد پیش‌فرض** (شماره واحد از لیست)
3. **زیرمجموعه‌ها** (اختیاری — با کاما جدا کنید)

مثال: کالای «شکر» با زیرمجموعه‌های «کوهرنگ, اصفهان, صنوبر»

### افزودن واحد

از منوی ☰ → **📏 واحدهای اندازه‌گیری** → **➕ افزودن واحد جدید**

| فیلد | توضیح |
|---|---|
| کد واحد | مثلاً `kg`, `pcs`, `ton` |
| نام نمایشی | مثلاً «کیلوگرم» |
| ضریب تبدیل | مقدار کیلوگرم معادل ۱ واحد |

**مثال ضریب‌ها:**
- کیلوگرم: `1`
- گرم: `0.001`
- تن: `1000`
- کیلو (شکر): `1`
- عدد (کارتن): خالی بگذارید

### افزودن سریع از فرم

داخل فرم ثبت، کنار هر فیلد دکمه **➕** وجود دارد:
- کنار کالا → افزودن کالای جدید
- کنار واحد → افزودن واحد جدید
- کنار طرف حساب → افزودن فروشنده/خریدار
- کنار راننده → افزودن راننده

## 🔑 تغییر پسورد

### روش ۱ — Console مرورگر

1. `F12` بزنید
2. تب **Console**
3. این را بزنید:

```javascript
btoa('پسوردجدیدتو')
```

4. خروجی را کپی کنید (چیزی شبیه: `I0FhMDkxNTEyMTcyNzA=`)
5. فایل `index.html` را با Notepad باز کنید
6. این خط را پیدا کنید:

```javascript
const _BP_B64 = 'I0FhMDkxNTEyMTcyNzA=';
```

7. مقدار داخل کوتیشن را با خروجی جدید عوض کنید
8. ذخیره کنید

### تست پسورد

برای مطمئن شدن، در Console بزنید:

```javascript
atob('I0FhMDkxNTEyMTcyNzA=')
```

باید بدهد: `#Aa09151217270`

## 🔧 عیب‌یابی

### ❌ توکن دسترسی نداره (خطای ۴۰۳)

**علت:** توکن ساخته‌شده دسترسی `Contents: Read and write` ندارد.

**راه‌حل:**
1. توکن جدید بسازید
2. در **Repository permissions** → **Contents** → **Read and write** ✅
3. توکن قدیمی رو حذف کنید
4. توکن جدید رو در برنامه وارد کنید

### ❌ خطا در دریافت / ذخیره

- اینترنت را چک کنید
- نام کاربری و نام مخزن را دوباره بررسی کنید
- توکن را مجدد وارد کنید
- اگه توکن منقضی شده، توکن جدید بسازید

### ❌ داده‌ای روی GitHub ذخیره نشده

اولین بار که برنامه رو باز می‌کنید، فایل `data.json` هنوز روی GitHub ساخته نشده. با اولین **⬆️ ذخیره** ساخته میشه.

### ❌ دو کاربر همزمان ذخیره می‌کنند

در حال حاضر سیستم **ad-hoc** هست — آخرین نفر برنده‌ست. برای جلوگیری:
- قبل از ذخیره، اول **⬇️ دریافت** بزنید
- اگه پیام «تغییرات ذخیره‌نشده» اومد، اول ذخیره کنید

### ⚠️ حجم فایل نزدیک ۱ مگابایت

GitHub فایل‌های بزرگتر از ۱ مگابایت رو برای این API محدود می‌کنه.
- زیر ۴۰۰ کیلوبایت: عالی
- بین ۴۰۰ تا ۹۰۰: هشدار (زرد)
- بالای ۹۰۰: خطر (قرمز) — سریعاً بکاپ بگیرید و رکوردهای قدیمی رو حذف کنید

## 🔒 نکات امنیتی

### ✅ چیزهایی که این سیستم محافظت می‌کند

- پسورد بخش پشتیبان (Base64)
- اطلاعات GitHub فقط در مرورگر شما ذخیره می‌شود
- توکن در `localStorage` نگه داشته می‌شود (نه در فایل)

### ⚠️ چیزهایی که این سیستم محافظت نمی‌کند

- **پسورد پشتیبان** قابل دور زدن با DevTools است
- **توکن GitHub** در `localStorage` قابل خواندن است (برای کسی که به مرورگر شما دسترسی دارد)
- اطلاعات بین مرورگرها همگام نمی‌شود (مگر با GitHub)

### 💡 توصیه‌های امنیتی

1. **توکن GitHub** رو در جای امن نگه دارید
2. توکن رو **فقط با دسترسی Contents** بسازید (نه full access)
3. **Expiration** توکن رو حتماً تنظیم کنید
4. اگه توکن لو رفت → در GitHub سریعاً **Revoke** کنید
5. برای امنیت بیشتر، مخزن رو **Private** کنید
6. **هر روز** یک بکاپ فایلی بگیرید
