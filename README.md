## 📖 درباره پروژه

نرم‌افزار مدیریت انبار **کارخانه قند صنوبر** (شرکت صنایع غذایی سایه سار صنوبر آریا) یک **Progressive Web App** تک‌فایلی است که به‌صورت کامل روی مرورگر اجرا می‌شود و نیازی به سرور اختصاصی ندارد.

داده‌ها به‌صورت **آفلاین** در حافظه مرورگر نگهداری می‌شوند و با استفاده از **GitHub API** روی مخزن کاربر همگام‌سازی می‌شوند.

### ✨ ویژگی‌های اصلی

- 🖥️ **اجرا روی هر مرورگری** — بدون نیاز به نصب
- 📴 **کار در حالت آفلاین** — داده‌ها در localStorage ذخیره می‌شوند
- ☁️ **همگام‌سازی چند دستگاهی** — با GitHub Contents API
- 📅 **تقویم جلالی** با پیاده‌سازی داخلی
- 🔢 **اعداد فارسی** در تمام رابط کاربری
- 🌙 **حالت شب** با ذخیره تنظیمات
- 🖨️ **گزارش‌گیری حرفه‌ای** (A4/A5 - پرتره/افقی)
- 📊 **خروجی CSV** برای اکسل
- 🔐 **مدیریت هوشمند حذف** با Tombstone
- ⚡ **سبک و سریع** — فایل نهایی حدود ۱۵۰ کیلوبایت

## 🚀 راه‌اندازی سریع

### پیش‌نیازها

- یک مرورگر مدرن (Chrome، Firefox، Edge، Safari)
- یک حساب [GitHub](https://github.com) رایگان

### گام ۱ — Fork کردن مخزن

روی دکمه **Fork** در بالای صفحه کلیک کنید یا مخزن را Clone کنید.

### گام ۲ — فعال‌سازی GitHub Pages

1. به **Settings → Pages** بروید
2. در قسمت **Source** گزینه `Deploy from a branch` را انتخاب کنید
3. Branch را روی `main` و پوشه را روی `/root` تنظیم کنید
4. روی **Save** کلیک کنید
5. چند دقیقه صبر کنید تا سایت بالا بیاید

آدرس سایت شما: `https://USERNAME.github.io/REPOSITORY/`

### گام ۳ — ساخت Personal Access Token

1. به [GitHub Settings → Tokens](https://github.com/settings/tokens) بروید
2. روی **Generate new token (classic)** کلیک کنید
3. نام دلخواه وارد کنید (مثل `Warehouse Sync`)
4. در بخش **Scopes**، گزینه `repo` را انتخاب کنید
5. روی **Generate token** کلیک کنید
6. **توکن را کپی کنید** (فقط یک بار نمایش داده می‌شود)

### گام ۴ — اتصال برنامه

1. سایت را باز کنید
2. روی آیکون **☰** (تنظیمات) کلیک کنید
3. بخش **☁️ اتصال GitHub** را باز کنید
4. اطلاعات زیر را وارد کنید:
   - **Username**: نام کاربری GitHub
   - **Repository**: نام مخزن (مثلاً `Warehouse`)
   - **Token**: توکن ساخته‌شده
5. روی **💾 ذخیره و تست اتصال** کلیک کنید

✅ اگر پیام **دسترسی کامل** را دیدید، همه چیز آماده است!

## 📚 راهنمای استفاده

### ثبت ورود کالا

1. روی دکمه **📥 ورود کالا** کلیک کنید
2. فرم باز می‌شود — فیلدها را پر کنید:
   - **تاریخ و ساعت** (خودکار = الان)
   - **کالا** (از لیست یا `+` برای جدید)
   - **زیرمجموعه** (اختیاری)
   - **تعداد و واحد**
   - **مجموع وزنی** (خودکار محاسبه می‌شود)
   - **فروشنده و راننده**
   - **شماره فاکتور، باسکول، بارنامه**
   - **توضیحات**
3. روی **💾 ثبت اطلاعات** کلیک کنید

### ثبت خروج کالا

مثل ورود است، فقط دکمه **📤 خروج کالا** را انتخاب کنید و فیلد **خریدار** جایگزین فروشنده می‌شود.

### همگام‌سازی

- **⬇️ دریافت**: داده‌ها را از GitHub می‌خواند
- **⬆️ ذخیره**: تغییرات را روی GitHub می‌نویسد

> 💡 **نکته مهم**: اگر تغییرات ذخیره‌نشده دارید و دکمه «دریافت» را بزنید، پیام هشدار می‌گیرید.

### گزارش‌گیری

- **📅 خلاصه روزانه**: ماتریس تاریخ × کالا (وزنی/شمارشی)
- **🖨️ گزارش کامل**: جدول کامل با جمع کل
- **📊 CSV**: خروجی برای Excel
- **👁️ مشاهده رسید**: پیش‌نمایش A5 برای چاپ

### تنظیمات پیشرفته (منوی ☰)

| بخش | کاربرد |
|---|---|
| 👤 نام کاربری | نامی که در تاریخچه Git ثبت می‌شود |
| 🌓 حالت شب | تم تاریک |
| 📦 کالاها | مدیریت کالاها و زیرمجموعه‌ها |
| 📏 واحدها | مدیریت واحدها + ضریب تبدیل |
| 🏪 فروشندگان | مدیریت لیست فروشندگان |
| 🛒 خریداران | مدیریت لیست خریداران |
| 🚚 رانندگان | مدیریت لیست رانندگان |
| ☁️ GitHub | اتصال و همگام‌سازی |
| 📁 پشتیبان | بکاپ، بازیابی، پاک‌سازی |
